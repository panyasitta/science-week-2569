# เว็บไซต์งานสัปดาห์วิทยาศาสตร์ 2569

เว็บไซต์ประชาสัมพันธ์งานสัปดาห์วิทยาศาสตร์แห่งชาติ โรงเรียนทุ่งเสลี่ยมชนูปถัมภ์ ปีการศึกษา 2569 ภายใต้แนวคิด

> “ตำราลับแม่มด ถอดรหัสเวทมนตร์ด้วยวิทยาศาสตร์”

ภายในเว็บไซต์ประกอบด้วยกำหนดการ รายละเอียดและกติกาการแข่งขัน 11 รายการ ระบบค้นหาและกรองตามระดับชั้น ลิงก์สมัคร ผลการแข่งขัน รายชื่อผู้เข้าแข่งขัน และเกียรติบัตร

## เว็บไซต์ที่เผยแพร่แล้ว

https://panyasitta.github.io/science-week-2569/

## เปิดใช้งานในเครื่อง

ต้องใช้ Node.js 22 ขึ้นไป

```bash
npm ci
npm run dev
```

## สร้างเว็บไซต์สำหรับ GitHub Pages

```bash
npm run build:github-pages
```

ไฟล์ static จะถูกสร้างไว้ในโฟลเดอร์ `github-dist/` โดย workflow ที่ `.github/workflows/deploy-pages.yml` จะสร้างและเผยแพร่เว็บไซต์อัตโนมัติเมื่อมีการอัปเดต branch `main`

GitHub Pages ของโครงการนี้ใช้ GitHub Actions เป็นแหล่งเผยแพร่

## การซิงก์ข้อมูล

ข้อมูลใช้งานถูกรวมไว้ใน `data/sync-data.json` และซิงก์กับฐานข้อมูลของ GPT Site อัตโนมัติ:

- แก้ `data/sync-data.json` บน branch `main` แล้ว GitHub Actions จะส่งเฉพาะส่วนที่เปลี่ยนไปยัง GPT Site ทันที โดยยืนยันตัวตนด้วย GitHub OIDC (ไม่ใช้ shared secret)
- แก้และเผยแพร่ข้อมูลผ่านหน้าแอดมินของ GPT Site แล้ว GitHub Pages จะอ่านข้อมูลล่าสุดทันที และ workflow จะสำรองกลับเข้า `data/sync-data.json` ภายในประมาณ 5 นาที
- ถ้ามีการแก้คนละฟิลด์หรือคนละทีม ระบบจะผสานทั้งสองฝั่ง ส่วนการแก้รายการเดียวกันจะใช้การแก้ล่าสุดเป็นหลัก

## โครงสร้างสำคัญ

- `app/page.tsx` — หน้าเว็บไซต์และระบบโต้ตอบ
- `data/sync-data.json` — ชุดข้อมูลกลางสำหรับกิจกรรม ผู้เข้าแข่งขัน ผลการแข่งขัน และเกียรติบัตร
- `app/globals.css` — รูปแบบและการแสดงผลทุกขนาดหน้าจอ
- `public/` — ภาพประกอบและไฟล์กติกา
- `github-pages/` — จุดเริ่มต้นสำหรับการสร้างเว็บไซต์แบบ static
- `vite.github.config.ts` — การตั้งค่าการสร้างไฟล์สำหรับ GitHub Pages
