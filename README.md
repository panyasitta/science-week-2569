# เว็บไซต์งานสัปดาห์วิทยาศาสตร์ 2569

เว็บไซต์ประชาสัมพันธ์งานสัปดาห์วิทยาศาสตร์แห่งชาติ โรงเรียนทุ่งเสลี่ยมชนูปถัมภ์ ปีการศึกษา 2569 ภายใต้แนวคิด

> “ตำราลับแม่มด ถอดรหัสเวทมนตร์ด้วยวิทยาศาสตร์”

ภายในเว็บไซต์ประกอบด้วยกำหนดการ รายละเอียดและกติกาการแข่งขัน 11 รายการ ระบบค้นหาและกรองตามระดับชั้น ลิงก์สมัคร และไฟล์กติกาฉบับเต็ม

## เปิดใช้งานในเครื่อง

ต้องใช้ Node.js 22 ขึ้นไป

```bash
npm ci
npm run dev
```

## สร้างเว็บไซต์สำหรับ GitHub Pages

```bash
npm run build:github-pages
```

ไฟล์ static จะถูกสร้างไว้ในโฟลเดอร์ `github-dist/` โดย workflow ที่ `.github/workflows/deploy-pages.yml` จะสร้างและเผยแพร่เว็บไซต์อัตโนมัติเมื่อมีการอัปเดต branch `main`

เมื่อตั้งค่า repository ครั้งแรก ให้เปิด `Settings` → `Pages` และเลือก `Source: GitHub Actions`

## โครงสร้างสำคัญ

- `app/page.tsx` — หน้าเว็บไซต์และระบบโต้ตอบ
- `app/competitions.ts` — ข้อมูลรายการแข่งขัน กติกา และลิงก์สมัคร
- `app/globals.css` — รูปแบบและการแสดงผลทุกขนาดหน้าจอ
- `public/` — ภาพประกอบและไฟล์กติกา
- `github-pages/` — จุดเริ่มต้นสำหรับการสร้างเว็บไซต์แบบ static
- `vite.github.config.ts` — การตั้งค่าการสร้างไฟล์สำหรับ GitHub Pages
